# tiny-stack-vm-20261122

A tiny stack virtual machine for make.fun's "Build a tiny stack virtual machine, 22 November 2026" bounty. One file, Node 22, standard library only: it reads every program in `/input`, runs the ISA v1 bytecode, and writes each answer to `/output`.
